# Appunti NIN — Parte teorica e archivio materiali studio/lavoro

App unica per docenti, con tre strumenti collegati da un menu in alto, per lavorare sulle nuove Indicazioni nazionali (**D.M. 9 dicembre 2025, n. 221**) e sulla progettazione didattica.

*IC Orbassano 2 — realizzato da Ins. Sonia Cercelletta*

## Come aprirla

- **Online** (dopo aver attivato GitHub Pages): `https://TUONOMEUTENTE.github.io/NOME-REPOSITORY/`
- **In locale**: scarica `index.html` (oppure `index.txt` e rinominalo in `index.html`) e aprilo nel browser con un doppio clic. Non serve installare nulla.

## Le tre sezioni

### 📌 Concetti da memorizzare
94 note adesive sul curricolo verticale e sulle UdA, con ricerca, filtri per area e per uso, modalità Ripasso a schede, annotazioni personali e possibilità di aggiungere note proprie.

### 🗂️ Argomenti e punti chiave
38 argomenti e 259 punti chiave, organizzati per tema (testo ufficiale, curricolo verticale, progettazione didattica, discipline, da verificare). Ogni punto ha lo spunta-quando-lo-sai e, dove serve, il riferimento normativo o la pagina del volume MIM. Include la «modalità memoria», che copre l'inizio di ogni punto per allenare il ricordo.

### 🧩 Archivio UDL
Progettazioni per l'inclusione secondo il modello UDL (Universal Design for Learning), organizzate per infanzia, primaria e secondaria di primo grado, più uno spazio con il modello vuoto da compilare per crearne di nuove.

Ogni sezione salva i propri progressi separatamente nel browser; passare da una scheda all'altra non fa perdere i dati delle altre.

## Sicurezza

È un unico file HTML con CSS e JavaScript inclusi. Non contiene eseguibili, non fa richieste di rete, non usa `eval` né script esterni. Le uniche risorse esterne caricate automaticamente sono i caratteri di Google Fonts; i link a Gazzetta Ufficiale, MIM ed EUR-Lex compaiono solo nel testo delle note e si aprono solo se cliccati.

Se il browser o l'antivirus bloccano il download del file `.html`, usa `index.txt`: contiene lo stesso identico codice.

## Fonti

- **Indicazioni nazionali per il curricolo della scuola dell'infanzia e del primo ciclo d'istruzione**, D.M. 9 dicembre 2025, n. 221 (GU n. 21 del 27/01/2026), Ministero dell'Istruzione e del Merito, marzo 2026.
- Materiali del corso di formazione 2025/26 «Principi organizzatori delle Indicazioni nazionali. Modulo teorico generale»: Perla, Magni, Costa, Cioffi, Balbo, Borgogni, Morri, Vespri, Valerio, Scotto Di Luzio.
- CAST, *Universal Design for Learning Guidelines*, versione 3.0, 2024.

Ogni nota indica la propria fonte; dove compare «lettura di…», «esempio redazionale» o «mio rimando» si tratta di un'interpretazione o un'aggiunta di redazione, non di un testo ufficiale: va sempre verificata prima di essere citata.

## Avvertenze

- Le note sono sintesi a scopo di studio: controlla ogni citazione sul testo ufficiale prima di usarla in un documento.
- I materiali del corso restano dei rispettivi autori. Se il repository è pubblico, valuta se hai il consenso a ridistribuirli; in caso contrario usa un repository privato.

## Pubblicare su GitHub Pages

1. Crea un repository e carica `index.html` (o `index.txt` rinominato) e `README.md`.
2. **Settings → Pages → Build and deployment**: Source *Deploy from a branch*, Branch `main`, cartella `/(root)`, poi *Save*.
3. Dopo uno o due minuti la pagina è online all'indirizzo indicato in cima alla schermata Pages.

Senza scaricare il file: su GitHub usa *Add file → Create new file*, chiama il file `index.html` e incolla il contenuto di `index.txt`.
